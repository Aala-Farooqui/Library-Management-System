# Library Management System

## About the Project
A DBMS mini-project developed using MySQL to manage library books, registered members, book issues, returns, and late-return fines.

## Technologies Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
1. **Books** — Stores book information and available copies.
2. **Members** — Stores registered library members.
3. **Issues** — Maintains book-issuing and return records.
4. **Fines** — Stores late-return fine details.

## Features
- Book and member management
- Book issue and return tracking
- Book availability management
- Fine calculation
- SQL JOIN queries and reports
- Primary and foreign key relationships

## How to Run
1. Install MySQL Server and MySQL Workbench.
2. Open MySQL Workbench.
3. Create a new SQL query tab.
4. Open `library_db.sql`.
5. Execute the SQL script to recreate the database and sample records.
6. Run `USE library_db;` and `SHOW TABLES;` to verify the database.
